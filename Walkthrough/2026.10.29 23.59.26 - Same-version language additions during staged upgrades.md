# Same-version language additions during a staged upgrade

The installed3.0.0 preview had already generated language files before two final sound-group labels were added. The final binary retained the same assembly version, so LocManager's version stamp considered the303-entry files current. ApplicationServices correctly rejected startup with Language tr is missing BuiltInSounds. This was specific to the staged same-version installation; an ordinary2.x-to-final3.0.0 launch refreshes its older stamp.

The installed language documents were repaired by appending only missing keys from the final compiled Turkish fields and embedded English XML. Existing translations were retained; both documents received two entries and the final installed panel returned an accepted version-three acknowledgement. When adding strings after testing an unpublished build with the same version, account for its already generated language files. Preserve hand edits and merge missing defaults rather than erasing the user's documents or bypassing language validation.
