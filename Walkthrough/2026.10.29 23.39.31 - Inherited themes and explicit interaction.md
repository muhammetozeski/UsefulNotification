# Inherited themes, accepted policies and explicit interaction

UsefulNotification now implements the approved inherited-theme redesign. The accepted visual is the static inward translucent frame with Snooze preserved in body-acknowledgement mode; the later S-shaped ribbon proposal was rejected. Design/Approved.html retains the accepted reference. Themes own appearance, sound and delivery; user-created children retain actual parent identity and only their own patches. See [Appearance](../Docs/Appearance.md) for the maintained contract.

The selected theme is flattened before applying per-send Overrides. Flattening the already overridden result would make clearing an override return the overridden value rather than the inherited baseline. Captured omission/provenance flags preserve content-aware lifetime/interaction and explicit text colors through JSON. The hub also keeps each occurrence's resolved policy, so editing a later recurrence does not recolor an earlier result. Partial override updates merge containers while supplied Change objects remain atomic, including explicit-null silence.

Independent review identified five integration faults: adaptive colors overwrote explicit AccentText; legacy Level stopped selecting its compatibility accent; the surface sorted raw rather than resolved priority; equal-duration Overrides.Lifetime edits did not restart expiry; and duplicate theme documents replaced one another by enumeration order. These paths were corrected and covered by focused Core/Razor checks. Names are display metadata, not control-flow markers for content policies. Version-three callers negotiate their wire contract, while the same host continues to answer older clients with version two.

Sound playback now reuses bounded in-memory PCM, synthesized from actual waveform/envelope objects. Completion, snooze, replacement and shutdown cancel occurrence-owned playback; explicit silence emits no playback event. Editor auditions remain independently cancellable. The three urgent beeps have constant frequency; ordinary presets use quiet decay and harmonics. A real Windows delivery exercised the synthesized stream without MediaFailed or fallback errors.

Direct browser preview of saved SSR files was blocked by tool URL policy. The native screenshot helper also lacked its kernel assets, so no native visual confirmation is claimed; handler/SSR evidence and the user's own open panel remain distinct.
