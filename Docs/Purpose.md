# Why these guides exist

UsefulNotification is an integration tool. Its request defaults, acknowledgement rules, template bridge, and portable layout must be discoverable without reading the entire implementation. These guides preserve those contracts and the packaging conditions that took work to establish.

The index selects the necessary topic. Source definitions remain the authoritative field inventory; examples explain how those fields work together. Runtime results and their scope belong beside the relevant method. Transient progress belongs in dated Walkthrough records, not in the integration contract.
